Capacidades y Características

¿Qué hace ClimaSense AI?

Una arquitectura diseñada de extremo a extremo para evitar fallas por sobrecalentamiento, optimizar el uso de energía y garantizar resiliencia total frente a cortes de Internet.

📡

Telemetría Edge Nativa

Captura continua de temperatura (°C) y presión barométrica (Pa/hPa) usando el sensor I2C BMP280 mediante un plugin de alto rendimiento compilado en ARM64.

🛡️

Resiliencia Offline & Purga 5 Min

Si la red falla, la Raspberry Pi almacena los datos localmente en SQLite (modo WAL) con secuencias monótonas y purga automática a los 5 minutos tras reanudar la sincronización.

🌤️

Microclima y OpenStreetMap

Integración con Nominatim OSM y GPS para obtener coordenadas exactas y consultar automáticamente el clima exterior real con Open-Meteo API.

🧠

GroqCloud AI Llama 3.3 70B

Análisis contextual cada 10 minutos (10 muestras). Evalúa la tendencia térmica y genera un resumen corto con un diagnóstico extendido y plan de acción de 3 pasos.

🧹

Higiene de Datos (Auto-Pruning)

El servidor purga automáticamente las mediciones históricas brutas conservando únicamente las 100 muestras más recientes por dispositivo, manteniendo la base de datos ligera y veloz.

📊

Panel Paginado e Historial

El dashboard del cliente limita las tarjetas a las 3 recomendaciones más recientes, ofreciendo el botón "[ Leer más ]" y un modal de historial paginado de 10 en 10.

Requisitos de Infraestructura

¿Qué se necesita para funcionar?

Todo lo necesario para poner en marcha un nodo de monitoreo inteligente en tu sala de servidores o infraestructura crítica.

⚡ Requisitos de Hardware (Edge Node)

  • ✓
    Raspberry Pi: Cualquier modelo (Zero W, Zero 2 W, 3B+, 4B o 5) corriendo Raspberry Pi OS (64-bit).
  • ✓
    Sensor de Precisión: Sensor digital BMP280 conectado por bus I2C (Dirección `0x76` en pines SDA/SCL).
  • ✓
    Almacenamiento Local: Tarjeta MicroSD de mínimo 4 GB con soporte de escritura SQLite.
  • ✓
    Conectividad: Red Wi-Fi o Ethernet para transmitir lotes WebSocket al servidor SaaS.

☁️ Requisitos de Software & Servidor SaaS

  • ✓
    Joss Engine Runtime: Joss v3.6.4 instalado en el servidor (soporta Linux ARM64 y x86_64).
  • ✓
    Base de Datos: PostgreSQL 14+ (Producción HestiaCP) o SQLite local (Desarrollo).
  • ✓
    GroqCloud API Key (Opcional): Variable `GROQ_API_KEY` para activar Llama-3.3-70b AI recommendations.
  • ✓
    Nginx / Reverse Proxy: Soporte de cabeceras WebSocket (`Upgrade`, `Connection`) para eventos en vivo.
